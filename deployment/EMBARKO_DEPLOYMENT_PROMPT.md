# Official Embarko deployment prompt

Captured on 24 Nov 2026 from the "Copy deployment prompt" button on https://embarko.ai/. This is the exact text the button copies.

```
Put this online with Embarko and give me the link to share. It can be one HTML page, a report, a deck, a dashboard or a full app. No Dockerfile, no signup.

Read https://embarko.ai/docs/quickstart.md and follow it. Nothing to install.
Deploy anonymously first — no Embarko key, no account — then give me the live URL.
Only once it's live, ask me for my email: Embarko mails back an Embarko key that makes the app permanent.

Faster, if your tools let you install one: npx skills add embarko-ai/skill --skill embarko-deploy -g
```
